# IBM-project
This repository showcases some of the tasks and exercises I completed while learning Data Science through IBM’s course program. It provided me with valuable hands-on experience and helped me build a strong foundation in core data science concepts and tools.

Throughout these tasks, I practiced essential skills such as:

Data aggregation and summarization using Pandas
Data visualization with Python
Building and evaluating machine learning models using Scikit-learn
Exploring reinforcement learning concepts
Working with various data science techniques and workflows

This repository does not represent one complete end-to-end project; instead, it highlights parts of my learning journey and demonstrates the practical exercises I worked on during the course.

It is only a small snapshot of what I learned, as much of the coursework and projects were completed directly on IBM’s online platform and were unfortunately not saved at the time.

This collection reflects my progress, curiosity, and commitment to developing my skills in Data Science and Machine Learning.
